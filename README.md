## 👩‍💻 CodSoft_To-Do-List-Application
A responsive To-Do List Application built using HTML, CSS, and JavaScript. Features include task management, validation, search, filtering, Local Storage persistence, task categories, priorities, due dates, and dark mode.

## ✨ Features
- Add, edit, delete, and complete tasks
- Form validation
- Search tasks by name
- Filter all, pending, and completed tasks
- Completed and pending task counters
- Task categories and priority levels
- Due dates
- Dark mode
- Responsive mobile and desktop layouts
